# CS2-Custom-Room-CFG

CS2 跑图练习配置

## 使用
控制台执行：

```
exec training
```

## ⌨️ 快捷键
| 按键 | 功能 |
| ---- | ---- |
| F8 | 打印帮助 |
| - | 添加T BOT并放置 |
| = | 添加CT BOT并放置 |
| n | 准星处放置BOT |
| \ | 切换BOT蹲/站 |
| , | 重投上一颗投掷物 |
| . | 清除烟闪火等效果 |
| / | X光实体查看 |
| F9 | 发爪子刀 |
